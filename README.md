# first-pr-practice

Một project nhỏ để luyện quy trình tạo Pull Request trên GitHub.

## Nội dung

- `src/text.js` — các hàm xử lý chuỗi đơn giản: `capitalize`, `slugify`.
- `test/text.test.js` — kiểm thử bằng trình chạy test có sẵn của Node.js.

## Cách chạy kiểm thử

Yêu cầu Node.js 18 trở lên.

```bash
npm test
```

## Đóng gớp

Tạo nhánh mới, commit thay đổi rồi mở Pull Request vào nhánh `main`.
